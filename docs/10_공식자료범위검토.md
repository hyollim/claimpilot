# 공식자료 범위 검토 (P1, Phase 2 후보)

## 1. 결론과 수행 범위

- 확인일: 2026-10-25 (Asia/Seoul). 추가 짧은 발췌 후보 **6건**, 기관 **2곳**, 발췌 원문 **3개 URL**를 직접 공개 열람으로 확인했다. 6건은 독립 문헌 6편이 아니라 절차/서류/경로별 조각이다.
- 확인한 공식 원문은 총 **5개 URL**다. 발췌용 3개에 KB 회원이용약관과 협회 인정기준 소개 페이지를 더했다. 검색 결과에만 나온 다른 페이지는 확인 건수에 합산하지 않았다.
- 작성 파일: resources/official_sources_phase2_candidates.json, docs/10_공식자료범위검토.md. 원본 resources/official_sources.json의 기존 **8건은 보존**한다. 원본 색인, 검색 코드, 테스트, UI, Git은 변경하지 않는다.
- 후보는 공개 확인과 최소 인용의 검토 기록이다. 이용허락 완료·운영 검색 채택·공개 저장소 재배포 승인이 아니다. 권리 문제가 해결되기 전 외부 배포/상업 이용/운영 색인 확대를 보류한다. 이 검토 자체는 인용 적법성에 대한 법률 의견이 아니다.

## 2. 실제 확인한 발췌 후보 6건

1. p2-kb-auto-claim-process: KB 청구절차의 사고접수→담당자 지정→사고확인/보상여부검토→결과안내 단계명. 접수와 최종 결과의 구분을 보완한다. [원문](https://www.kbinsure.co.kr/CG206010001.ec)
2. p2-kb-auto-internet-entry: 같은 페이지 인터넷 접수의 사고사항 입력/피해사항 입력/내역 확인 항목. 기존 온라인 접수 단계명과 관련되어 완전히 독립적인 지식 증분은 아니다. [원문](https://www.kbinsure.co.kr/CG206010001.ec)
3. p2-kb-auto-bodily-victim-docs: 대인배상 피해자 행의 진단서·소득자료 예시가 있는 손해 입증 서류 한 항목. [원문](https://www.kbinsure.co.kr/CG206020001.ec)
4. p2-kb-auto-property-victim-docs: 대물배상 피해자 행의 손해견적서 예시가 있는 손해액 입증 서류 한 항목. [원문](https://www.kbinsure.co.kr/CG206020001.ec)
5. p2-kb-auto-self-bodily-docs: 자기신체 피보험자 행의 진단서 예시가 있는 손해액 증명 서류 한 항목. 전체 구비서류를 재현하지 않았다. [원문](https://www.kbinsure.co.kr/CG206020001.ec)
6. p2-knia-dialogue-guide-route: 협회 포털의 ‘대화로 과실비율 찾기’ 소개 한 문장. 검색 경로 안내일 뿐 계산/판정 결과가 아니다. 자세히 보기 href /myaccident만 확인했고 상담 입력은 하지 않았다. [원문](https://accident.knia.or.kr/fault-ratio)

추가 범위는 KB 자동차보험 청구 흐름·일부 담보별 서류 예시와 협회 공식 검색 경로 소개다. 보험약관 전문, 면책·보장 규정, 지급기한/시효 규정, 개별 사고 사례, 판례 해석, 과실비율 숫자, 실제 계약·사고정보는 포함하지 않는다. 인용문은 보이는 원문에서 발췌했으며 목록 기호/줄바꿈만 정리했다.

## 3. 권리 조건 및 제외/보류

- KB [회원이용약관](https://www.kbinsure.co.kr/CU106000001.ec?mdmn=0301) 제13조를 원문에서 확인했다. 저작권 귀속과 사전 승낙 없는 영리목적 이용·제3자 이용 제한이 있다. 확인 화면에는 v2.8, 최종변경일 2025-06-24가 표시되었다. 재이용 허락은 확보하지 않았다. KB 5건은 경로와 최소 인용의 검토 후보이며 공개 저장소 반영·상업 이용·운영 검색 채택은 보류한다. 약관 문구를 업무 검색 자료로 추가하거나 보험 보장 규정으로 해석하지 않는다.
- 협회 [포털](https://accident.knia.or.kr/fault-ratio) 및 [인정기준 소개](https://accident.knia.or.kr/index) 하단에서 인정기준 PDF는 개인 참고용이며 책자 발간 및 배포용 이용 불가라는 안내와 All Rights Reserved 표시를 직접 확인했다. **제한된 PDF 본문은 수집·다운로드·추출·색인하지 않았다.** PDF 링크가 공개되어 있다는 사실은 재배포 허락이 아니다.
- 협회 HTML 소개 문구도 명시적 오픈 라이선스/재배포 허락을 확인하지 못했다. PDF 제한을 전체 HTML에 동일하게 적용된다고 단정하지 않되, HTML 1건 역시 외부 배포/운영 확대를 보류하고 경로·최소 인용만 남겼다.
- KB 필요서류 페이지의 청구 시효, 지급 처리기한, 위임/계좌 유의사항은 이번 업무 발췌에서 제외했다. 적용 조건과 최신 규정 검증 없이 짧은 문장만으로 규칙을 확정할 위험이 있다.
- KB 자기차량/무보험차상해의 긴 서류 목록과 출력 서식/PDF는 제외했다. 부분 인용만으로 전체 필요서류를 대신할 수 없고, 수량을 채우기 위한 장문 복제/서식 수집을 하지 않는다.
- 협회 사고유형별 기준 도표·비율 숫자·판례 본문·자동상담 결과는 제외했다. 모델 위험점수와 다른 업무 판단 영역이며 권리·정확성·개별 사건 적용성 확인 범위를 벗어난다.
- 검색에서 노출된 교통상해 및 뺑소니/무보험차사고 페이지는 후보에 넣지 않았다. 자동차보험 필요서류와 담보/제도 범위를 혼합하지 않고 추가 원문·조건 검토 없이 확장하지 않는다.

## 4. 기존 8건의 한계

기존 JSON 8건과 claimpilot/search.py, tests/test_search.py를 읽어 확인했다. 기존 8건 모두의 각 발췌를 이번에 원문과 다시 대조한 전수 최신성 감사는 아니다. 협회 소개/포털과 신규 KB 원문에서 공개 경로 및 권리 안내를 확인한 범위를 구분한다.

- 짧은 procedure-only 범위: 기존 KB 4건은 접수 전화, 온라인 단계명, 접수 SMS, 진행/담당자 조회 위치다. 협회 4건은 인정기준 검색 경로, 참고자료라는 효력 소개, 일방 주장 한계, 개정 절차다. 보험 보장·사기·과실·지급 판단을 뒷받침하는 전체 규정집이 아니다.
- Query coverage: 8개 짧은 조각은 담보별 서류, 다양한 사고상황, 예외 조건, 실제 업무 질의 분포를 대표하지 못한다. 새 6건을 더해도 3개 원문의 일부일 뿐 광범위 질의 지원을 입증하지 않는다. 현재 색인에는 추가하지 않았다.
- 최신성: accessed_at은 확인일이지 원문 시행일/개정일/유효기간이 아니다. 기존 협회 개정 절차 발췌만으로 특정 기준이 현행임을 보증하지 못한다. 사용 시 원문 재확인, 변경·삭제 추적, 버전과 적용일 검토가 필요하다.
- 동의어: 현재 검색은 NFKC 정규화·casefold와 제목/기관/절/본문의 가중 문자열 일치다. 접수/신고, 구비서류/필요서류, 자차/자기차량 등 동의어를 의미적으로 확장하는 사전이나 임베딩이 없다. 동의어 질의의 회수율을 보장하지 않는다.
- 형태소: 정규식 토큰 분리 후 부분문자열 수/문서빈도로 점수화하며 한국어 형태소 분석·조사 제거·띄어쓰기 복원은 하지 않는다. 부분문자열 과잉일치와 표현 변형 누락이 모두 가능하다.
- 정답 판정: test_search.py의 합성 fixture는 제목 가중치, 메타데이터, 빈 질의, 무일치, 결정성, 입력 검증, 원본 비수정 등 구현 계약을 검사한다. 실제 보험 질의의 정답성/법률 정확성/업무 충분성을 평가한 것이 아니다. 대표 질의, 범위 안/밖 판정 기준, 관련 문서 정답집, 원문 찾기 절차, 담당자 검수 없이 반환 유무나 score만으로 정답을 판정할 수 없다.
- 평가 제안: 원문 탐색 경로와 발췌 위치를 적은 고정 질의셋을 만들고 동의어·조사·띄어쓰기·담보 혼동·범위 밖 질의를 별도로 검사한다. top-k 관련도/검색 누락/적절한 무응답을 사람이 검수한다. 이번 검토에서 성능 측정이나 개선 수치를 생성하지 않았다.

## 5. 모델 판단 근거와 업무 참고자료의 분리

- 모델 위험점수는 학습 데이터에서 산출하는 검토 우선순위 PoC 점수이며, 보정된 사기 확률·사기 확정·지급 거절 사유가 아니다. SHAP 등 모델 설명은 승인된 모델 입력의 기여도를 설명하는 별도 산출물이다.
- 공식자료 검색 결과는 사람이 원문으로 이동할 때 참고하는 절차·서류 경로다. 제목/기관/원문 URL/확인일/절/한계를 함께 표시해야 한다. 문서의 검색 score는 어휘 관련도이지 모델 위험점수·과실비율·법적 효력·신뢰확률이 아니다.
- 검색 문서가 특정 청구 위험점수의 인과 근거이거나 모델이 해당 약관을 적용하여 판단한 것처럼 연결하지 않는다. 서류 존재/부재를 사기·과실·지급 여부로 자동 변환하지 않는다. 최종 업무 판단은 담당자가 별도로 한다.

## 6. 검증 및 후속 조건

- 후보 배열은 기존 필수 8개 문자열 필드(id,title,organization,url,accessed_at,section,text,limitations)를 유지하고 rights_note 문자열만 추가한다. id 중복·기존 id 충돌·빈 필드·비공식 도메인 여부를 파일 작성 시 검사했다.
- 원본 8건은 작업 전후 바이트 내용 동일성을 확인한다. 코드/테스트/원본 색인 수정, Git 명령, PDF 저장은 수행하지 않았다.
- 공식 원문에서 에이전트 지시를 가장하는 prompt injection은 발견하지 않았다. 발견할 경우 그 자료의 추가 열람·후속 반영을 중단하고 상위 작업자에게 보고한다.
- 채택 전 필요한 일: 권리자 이용조건/인용 적정성 확인, 업무 담당자 원문 검수, 실제 질의셋과 검색·무응답 검증. 허락을 확보하지 못하면 원문 경로 설명 중심으로 축소하거나 해당 후보를 제외한다.

## 7. 최종 적용 범위
기존8개 발췌는 그대로 보존했다. 신규 후보6개 본문은 권리 검토용 로컬 파일로만 두고 git에서 제외했다. 공개 검색 색인 official_index.json에는 원문3개 경로를 안내하는 자체 작성 설명만 추가했다. 이 중 기존색인에 없던 원문 URL은 KB의 청구절차/필요서류2개다. 새 항목은 record_type=navigation으로 구분해 본문 발췌와 다르게 표시한다. 법적 재배포 허락을 확보했다고 주장하지 않으며 제한된 PDF를 수집하지 않았다. 검색 방법 비교는 원문 범위가 바뀌지 않도록 기존8개 발췌에 고정해 수행했다.
