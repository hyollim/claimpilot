## 원격 검증
- [기본 CI 성공](https://github.com/hyollim/claimpilot/actions/runs/40196974277): 데이터 산출물 없이 실행한 단위 테스트 경로.
- [실제 데이터 통합 CI 성공](https://github.com/hyollim/claimpilot/actions/runs/40197061417): Linux/Python 3.11에서 Kaggle 원본 다운로드 → 실제 학습 → 전체 테스트 **53 passed**(2.20초). 학습 로그에서 동일 SHA-256과 선정 Logistic Regression C=0.1을 확인했다.
- Linux SHAP 합계 오차는 1.332e-15다. CPU/OS 차이로 CatBoost depth=4의 조기종료 최적 반복은 로컬26, Linux0으로 달랐다. 모든 후보가 플랫폼에 관계없이 비트 단위 재현된다고 주장하지 않는다. 비교표와 통계 산출물은 명시한 macOS 실험 기준이며 선정 로지스틱 모델은 원격에서도 유지되었다.
- CI의 Node20 action 경고와 ubuntu-latest 이동 안내를 확인해 Node24 호환 action 커밋과 ubuntu-24.04로 실행 환경을 고정했다. 고정 환경의 [후속 통합 검증](https://github.com/hyollim/claimpilot/actions/runs/40197394670)도 성공했다(89e30b2). 기본 CI도 같은 커밋에서 성공했으며 action 런타임 경고가 사라진 것을 확인했다.
