# 03. 모델 평가 보고서

## 평가 절차
학습/검증/test는 9,252/3,084/3,084건이며 양성은 554/184/185건이다(seed=42). 19개 범주 입력을 사용한다. Logistic Regression은 one-hot·class_weight=balanced·max_iter=1500, C=0.1/1.0을 비교했다. CatBoost는 depth=4/6, 최대450회·학습률0.05·조기종료60회를 비교했다.

검증 AP 최대, 동률 시 검증 상위 20% 포집률로 선택했다. 검증 F1 최대 임계값을 고정한 뒤 test를 평가했다. 후보의 test 결과를 보고 재선정하지 않는 정책이다. 동일 설정으로 재현 실행했으며 최종평가 관측 후 튜닝하지 않았다. test 접근 차단이나 1회 평가 강제 장치는 미구현이다. 실제 코드와 반올림 전 수치: [train.py](../scripts/train.py), [metrics.json](../reports/metrics.json).

AP는 sklearn average_precision_score의 계단형 평균 정밀도이며 사다리꼴 PR 면적과 구분한다. 기준선은 학습 양성 비율의 상수 점수다. 동점은 원본 순서로 처리하므로 표의 기준선 상위 20% 포집 결과는 단일 순서에 의존하며 여러 무작위 추출의 평균이 아니다. 무작위 검토의 별도 기대 포집률은 617/3,084=20.0065%, 기대 리프트는1이다.

## 선정 모델의 실제 한계
Logistic Regression C=0.1의 임계값은 0.5573884366989108이다. test AP 0.130255, Precision 0.104463, Recall 0.594595, F1 0.177706. 이 Precision/Recall/F1은 임계값 기반이며 아래 검토 예산 지표와 다르다.

상위 20% 617건에서 양성 라벨 72/185건을 포집했다(포집률 38.92%, 정밀도 11.67%, 리프트 1.945315). 545건은 비사기 라벨(0)이며, 양성 113건은 상위 20% 밖에 남았다.

리프트는 상위20% 정밀도/전체 양성비율이다. 기준선보다 높지만 자동판정에 필요한 정밀도를 입증하지 않는다. 비보정 점수이며 Brier 0.215615는 상수 기준선 0.056389보다 나쁘다(작을수록 좋음). 확률 해석을 금지한다.

## 고정 예측 부트스트랩 95% 구간
최종 test 행을 복원추출하여 500회 평가하고 2.5·97.5 백분위수를 계산했다(seed=42).
- ap: 0.101728~0.171554
- capture_at_20: 0.320949~0.445750 (32.09%~44.58%)
- precision_at_20: 0.092382~0.141005 (9.24%~14.10%)

고정된 모델 예측의 표본 불확실성만 포함한다. 재학습 변동·데이터 수집 오류·한국 업무 이동·시계열 종속성을 반영한 구간이 아니다.

## 연도 이동 스트레스
1994·1995 자료를 학습8,502/검증2,835건으로 나누고 1996년 4,083건(양성213)을 holdout했다. 선정 모델 종류·파라미터를 유지해 별도 학습하고 해당 검증셋에서 임계값을 다시 정했다. 본 test 모델의 재선정에는 쓰지 않았다.

- AP 0.073166, Precision 0.062637, Recall 0.403756, F1 0.108449.
- 상위20% 817건 중 양성51건: 포집률 23.94%, 정밀도 6.24%, 리프트 1.196597. 비사기 라벨766건, 양성162건 미포집.
- 무작위 test AP 0.130255보다 낮다. 원 모델 종류 선정에는 1996년 일부 라벨이 포함되었다. 정확한 접수일과 Year의 의미도 미검증이므로 독립 미래검증이 아니라 연도별 이동 민감도 참고 결과다.

## 입력 독립성과 설명 검산·향후 개선
실제19개 입력 기준 중복행51개, 상충 라벨 입력그룹2개, 개발-test 공통 입력그룹19개가 관측되었다. 고객/사건ID가 없어 누수·독립성을 완전히 검증하지 못했다. 근거: [data_audit.json](../reports/data_audit.json).

SHAP 기여도+기준값과 raw log-odds의 최대 차이는 1.7763568394002505e-15다. 개별 설명 파일은 절대값 상위8개 요인과 나머지 기여도 합(other_contribution)을 저장한다. 산술 합산 일치일 뿐 설명의 업무 타당성 검증은 아니다. 전역값은 [global_shap.csv](../reports/global_shap.csv) 참조.

향후 과제는 원본 라벨·수집 시점 확인, 외부/시간순 데이터 평가, 검토 비용·누락 비용 수집, 별도 검증셋을 이용한 확률 보정 검토다. 달성한 개선으로 주장하지 않는다. 실행 테스트 결과와 검증 범위는 [검증결과](검증결과.md)에 기록했다.
