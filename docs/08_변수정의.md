# 08. 변수 정의: 33개 원본 열

## 해석 원칙
**원본 데이터 사전이 불충분하다.** 이 문서는 원본의 확정 업무 정의를 복원한 사전이 아니다. 수집지역·원래 라벨 정의·대상자·수집시점은 미검증이다. 아래에서 관측 사실(열명/자료형/고유값 수/표본 값), 명칭 기반 잠정 해석, 미확인 사항을 분리한다. 잠정 해석을 원본의 사실확정 의미로 사용하지 않는다.

자료형·고유값 수·표본은 [data_dictionary.csv](../reports/data_dictionary.csv)의 자동 관측 결과다. 예시는 전체 값 목록이 아닐 수 있다. 전 열의 pandas null 수는0이지만 0·none 등 특수 코드의 업무 의미는 미확인이다. 입력/제외 역할은 원본 정의가 아니라 [modeling.py](../claimpilot/modeling.py)의 프로젝트 결정이다. 19열 입력, 라벨1열+나머지13열 제외다.

## 별도 주의
- Age=0은320건, MonthClaimed='0'과 DayOfWeekClaimed='0'은 각1건이다. 정상값/결측/입력 오류를 임의 확정하지 않는다.
- Year는 1994/1995/1996을 관측했으며 연도 스트레스에만 사용한다. 정확한 접수일의 대체 변수로 확정하지 않는다.
- FraudFound_P는 0/1을 관측했고 프로젝트는1을 양성(사기 라벨)으로 평가한다. 법적 사기 확정·조사 완료 여부는 알 수 없다.
- Deductible·VehiclePrice의 통화나 국내 금액 환산을 만들지 않는다. PolicyType·BasePolicy를 한국 약관의 보장 의미로 단정하지 않는다.
