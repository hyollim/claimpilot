# 07. 최종 결과 보고서

## 현재 산출 범위
공개 자동차보험 청구의 검토 순위 실험과 로컬 담당자 화면을 작성했다. 데이터 다운로드·감사·모델 비교·점수/SHAP 산출, 검토 대기열·상세·상태/메모/체크리스트 저장, 공식 발췌8개 검색이 코드상 구현 범위다. 실제 접수 연계·운영 배포·사기/지급 자동판정은 포함하지 않는다.

## 실제 평가
- 데이터15,420건, 양성923건. train/validation/test=9,252/3,084/3,084.
- 선정 Logistic Regression C=0.1: AP 0.130255, Precision 0.104463, Recall 0.594595, F1 0.177706.
- 상위 20% 617건에서 양성 라벨 72/185건을 포집했다(포집률 38.92%, 정밀도 11.67%, 리프트 1.945315). 545건은 비사기 라벨(0)이며, 양성 113건은 상위 20% 밖에 남았다.
- 고정 예측 bootstrap 95%: AP0.101728~0.171554, 포집률32.09~44.58%, 상위20% 정밀도9.24~14.10%. 재학습·한국 업무 이동 불확실성은 포함하지 않는다.
- 1996 연도 스트레스 4,083건: AP0.073166/P0.062637/R0.403756/F10.108449, 상위20% 817건에서51/213건 포집(23.94%), 정밀도6.24%, 리프트1.196597. 1996년 일부 라벨이 원 모델 선정에 포함되어 독립 미래검증이 아니며 연도 의미·정확한 접수일도 미검증이다.

근거: [metrics.json](../reports/metrics.json), [data_audit.json](../reports/data_audit.json), [모델 평가](03_모델평가보고서.md).

실제 입력 기준 중복행51개·상충라벨 그룹2개·개발-test 공통 입력그룹19개가 있다. 고객/사건ID가 없어 독립성을 완전 검증하지 못했다.

## 검증 기록의 경계
이 문서는 기존 실행 산출물을 근거로 작성했으며 pytest를 재실행하지 않았다. 테스트 총수·개별 테스트·화면 검증 결과와 범위는 [검증결과](검증결과.md)에서 확인한다. 문서 존재나 모델 수치만으로 전체 검증 완료를 주장하지 않는다.

## 현재 전달 범위의 잔여 미완료 항목
**[blocked] GitHub HTTPS push**: 전용 저장소 생성만 완료했다. CLI HTTPS 인증 수단 부재로 원격 업로드를 완료하지 못했다. 인증 확보 후 제외 파일과 변경 범위를 검토하여 feature/claimpilot-mvp에 push하고 원격 반영을 확인해야 한다. main 병합·배포는 이 항목에 포함하지 않으며 별도 승인 대상이다.

원본 데이터·모델·검토 DB·개별 청구 점수/설명·분할명세는 .gitignore 제외 설정했다. 업로드 전 실제 추적 여부를 최종 확인해야 한다.

## 실운영 후속 작업: 현 PoC 미완료와 구분
다음은 현재 PoC에서 달성하지 않은 운영 전 후속 과제다.
1. 원본 라벨 정의·수집지역·변수 수집시점·데이터 이용조건 확인. 신규 국내 업무 데이터의 적법한 확보와 독립 평가.
2. 정확한 접수일 기반 시간 분할·외부 검증, 확률 보정 필요성 및 검토 예산/누락 비용 평가. 개선을 달성했다고 주장하지 않는다.
3. 인증·권한·동시성 제어·암호화·보관/삭제·변경불가 감사·백업복구·모니터링 설계와 검증.
4. 공식 발췌의 최신성·재배포 조건 점검. 전체 약관/RAG 확대는 별도 범위 검토.

한국 보험업무 성능, 지급액 절감, 처리시간 감소를 입증한 결과는 없다. 점수와 SHAP는 담당자 검토 단서이며 사기 증거나 자동 지급결정 근거가 아니다.
