## 분할과 전처리
seed=42의 계층 무작위 분할이다. 학습 9,252건/양성554, 검증 3,084건/184, 최종 test 3,084건/185이며 행 인덱스 중복은 없다. 실제 19개 입력 기준 중복행은 51개, 상충 라벨 입력 그룹은 2개, 개발(train+validation)과 test 공통 입력 그룹은 19개다. 행 인덱스 분리만으로 입력 패턴 독립성을 보장하지 못한다. 동일 입력이 동일 고객·사건이라는 뜻도 아니며 고객/사건 식별자가 없어 독립성을 완전히 검증할 수 없다. 19개 입력 모두 문자열 범주로 변환하며, Logistic Regression은 학습셋에서 one-hot encoder를 적합하고 미관측 범주를 무시한다.

라벨 1열과 제외 변수 13열을 합쳐 14열을 입력에서 뺐다. 나머지 변수도 실제 수집 시점이 불명확해 실무 누수 가능성이 남는다. 근거: [train.py](../scripts/train.py), [modeling.py](../claimpilot/modeling.py), [metrics.json](../reports/metrics.json).

## 설명값과 해석 제한
최종 test 평균 절대 SHAP 상위 변수는 BasePolicy 0.587193, PolicyType 0.347402, VehicleCategory 0.183524, Month 0.178250, MonthClaimed 0.152201이다. raw log-odds 단위이며 비율·원인·사기 증거가 아니다. 평균 절대값만으로 상승/하락 방향을 알 수 없다. 계약 유형 간 중복 정보의 영향도 검토해야 한다. 근거: [global_shap.csv](../reports/global_shap.csv).
