# 병렬 구현 계약
- 프로젝트 루트 /Users/hyolim/.aside/u/0/projects/claimpilot
- reports/metrics.json: models 목록(각 name, validation/test 사전), selected_model, threshold, split, features, excluded_features. 평가 키 ap, precision, recall, f1, capture_at_20, precision_at_20, lift_at_20, reviewed_count, captured_count, positives, n.
- reports/scored_claims.csv: 최종 test만. claim_id, risk_score, priority_rank, review_band, label, plus 원본 변수. model score는 보정된 사기 확률 아님.
- reports/explanations.json: claim_id를 키로 value {base_value,raw_score,factors:[{feature,value,contribution}]} SHAP raw log-odds 기여도.
- reports/data_audit.json: counts, splits, leakage, distributions 등 실제 측정.
- resources/official_sources.json: 공식 문서 발췌 배열 id,title,organization,url,accessed_at,section,text,limitations.
- claimpilot/review.py ReviewStore(path): get(claim_id) -> dict(status,note), save(claim_id,status,note) -> None, all() -> list[dict]. 상태 미검토/검토중/추가자료 요청/검토완료. SQLite.
- claimpilot/search.py search_sources(query,limit=5) -> list[dict] 출처 메타데이터 및 score 반환. 네트워크/생성 API 사용 없음.
- app.py Streamlit 앱. 위 파일 없을 때 실행 명령 안내. 최종 판단은 담당자. 라벨은 성능평가 탭에서만 표시, 실제 검토 화면에 정답 누수 금지.
