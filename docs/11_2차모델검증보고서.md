# 2차 모델 검증 보고서

## 무엇을 다시 확인했나
원본 MVP의 무작위 분할 결과를 덮어쓰지 않고 동일 입력 중복, 연도 이동, 검토량과 점수 보정을 따로 점검했다. 기준은 29d8b09와 reports/baseline_mvp다. 지표 근거는 [기존 평가](../reports/metrics.json), [2차 검증](../reports/phase2_validation.json), [보정 진단](../reports/phase2_calibration.json), [검토 예산](../reports/review_budget.csv)이다. 연구 모델을 신규 추론용으로 저장하거나 교체하지 않았다.

## 1. 검토 예산별 실측
기존 test 3,084건·양성 185건의 고정 점수를 내림차순 정렬했다. k=ceil(n×요청 비율), 동점은 기존 입력 순서다. 정밀도=포집/k, 포집률=포집/전체 양성, 리프트=정밀도/test 양성률이다. 무작위 기대 포집은 k×185/3,084로 계산한 기대값이지 실제 무작위 실험 결과가 아니다.

|요청 비율|실제 비율|검토 k|포집|포집률|정밀도|무작위 기대 포집|리프트|
|---:|---:|---:|---:|---:|---:|---:|---:|
|5%|5.026%|155|22|11.89%|14.19%|9.298|2.3661|
|10%|10.019%|309|39|21.08%|12.62%|18.536|2.1040|
|15%|15.013%|463|61|32.97%|13.17%|27.774|2.1963|
|20%|20.006%|617|72|38.92%|11.67%|37.012|1.9453|
|30%|30.026%|926|101|54.59%|10.91%|55.548|1.8182|
|40%|40.013%|1,234|123|66.49%|9.97%|74.024|1.6616|

20% 검토에도 비사기 라벨 545건이 포함되고 양성 113건이 남는다. 검토량을 늘리면 포집은 늘지만 정밀도가 일관되게 증가하지는 않는다. 무라벨 신규 CSV에는 포집률·정밀도·리프트를 계산하지 않는다. 건수 예산을 비용·절감액·처리시간 효과로 환산하지 않았다.

## 2. 동일 입력 그룹 격리와 연도 이동
승인된 19개 원문 입력의 값 조합을 그룹으로 묶었다. 중복 초과 51행·상충 라벨 그룹 2개를 재확인했다. 같은 입력은 같은 고객이나 사고라는 뜻이 아니다. 고객/사건 ID가 없어 실제 독립성·업무 누수 부재를 증명할 수 없다.

후보는 LR C=0.1/1.0, CatBoost depth=4/6이다. 학습에서만 fit하고 validation AP 최대, 동률이면 상위20% 포집률로 선정했다. 임계값은 선정 모델의 validation F1 최대이며 test에서 고정한다. CatBoost 조기종료에도 validation만 사용했다. 두 신규 분할 모두 LR C=0.1이 선정되었고 test는 선정 후 해당 모델 하나만 평가했다.

|평가|train/validation/test|test 양성|AP|상위20% 포집|상위20% 정밀도|임계값 F1|
|---|---|---:|---:|---:|---:|---:|
|원본 무작위|9,252/3,084/3,084|185|0.130255|72/185, 38.92%|11.67%|0.177706|
|입력 그룹 격리|9,251/3,086/3,083|182|0.144584|81/182, 44.51%|13.13%|0.200913|
|순수 연도 cutoff|8,502/2,835/4,083|213|0.0731656|51/213, 23.94%|6.24%|0.108449|

그룹 분할은 train/validation/test 사이 입력 그룹 교집합 0이다. 원본보다 수치가 높아도 평가 표본·양성 구성·임계값이 달라 개선 효과로 해석하지 않는다.

시간 실험은 1994~1995년 전체 11,337행을 75/25 계층 분할하여 선정하고 1996년 전체 4,083행을 평가했다. **미래 입력이나 라벨로 과거 행을 고르거나 제거하지 않았다.** 사후 감사에서 개발-1996 공통 입력 그룹 22개가 남았다. 시간 cutoff와 입력 그룹 격리는 서로 다른 질문의 실험이다.

초기에는 미래와 같은 입력을 가진 과거 22행을 purge하는 방식을 시도했다. 진단 AP 약 0.076508이 나왔지만, 미래 입력으로 선정 모집단을 바꾼다는 문제를 발견해 과거 전체를 유지하는 순수 cutoff로 수정했다. 이 초기 값은 설계 수정 이력일 뿐 현재 성과나 더 나은 결과로 사용하지 않는다. 현재 결과는 위 표의 0.0731656이다.

1996년은 이번 후보선정·임계값·조기종료에서 격리했지만 원래 MVP에서 이미 관측했다. 프로젝트 전체의 완전 unseen 미래검증이나 외부 검증은 아니다. Year의 실제 업무 시점 의미도 검증하지 못했다. 원본 보고서의 연도 스트레스와 이번 결과는 선정 절차가 다른 별도 실험이다.

## 3. 순위와 확률 보정은 별도 문제
class_weight=balanced는 학습 양성률 약6%와 달리 유효 가중 양성 비중을 1/2로 만든다. 가중 로그손실로 학습한 sigmoid 점수가 원 모집단의 사건 확률일 이유는 없다. AP가 상수보다 높아도 Brier가 나쁠 수 있다. 가중치는 규제하의 계수도 바꾸므로 차이를 단순 사전확률 이동 하나로만 설명하지 않는다.

원본 train 9,252행과 test 3,084행·순서를 보존했다. validation 3,084행을 calibration **1,542행**과 threshold selection **1,542행**으로 독립 분리했다. 각 92개 양성이며 행/claim ID 교집합은 0이다. 이는 고객/사건 독립성 또는 기존 입력 그룹 중복 해소를 뜻하지 않는다. train으로 기본 LR을 fit, calibration으로 raw logit의 sigmoid 보정, selection으로 각 조건의 F1 임계값을 고정한 뒤 test를 진단했다. 방법·C=1e6·네 조건은 사전 고정했다.

|연구 조건|test AP|Brier(낮을수록 좋음)|상위20% 포집률|F1|
|---|---:|---:|---:|---:|
|raw_balanced|0.130255|0.215615|38.92%|0.180438|
|raw_none|0.139121|0.054121|41.62%|0.185841|
|sigmoid_balanced|0.130255|0.054530|38.92%|0.180438|
|sigmoid_none|0.139121|0.054216|41.62%|0.185841|
|학습 양성률 상수|0.059987|0.056389|21.08%|0.113184|

raw_none의 Brier가 이 진단에서 가장 낮아도 test를 본 뒤 production을 바꾸지 않았다. sigmoid가 순위를 보존해도 값의 스케일은 바뀐다. 상수 점수의 상위20% 결과는 동점 입력 순서에 따른 값으로 순위 가치가 아니다.

raw_balanced의 AP와 포집은 원본과 같지만 F1은 다르다. 원본은 validation 전체로 임계값 0.557388을 정했고 연구는 selection 절반으로 0.565471을 정했기 때문이다. 원본 F1 0.177706을 0.180438로 수정하지 않는다.

보정 결과 역시 관측 라벨과 표본에 의존한다. 실제 사기 확률, 지급 판단, 외부 모집단의 확률 정확도를 보장하지 않는다. 신규 추론은 기존 **비보정** 모델을 그대로 쓴다.

## 4. 해석과 검증 경계
단일 seed·작은 후보 범위이며 신규 실험의 재학습 불확실성 구간은 제공하지 않는다. 원본 bootstrap은 고정 예측의 구간으로 해석한다. CatBoost 조기종료는 플랫폼에 따라 달라질 수 있어 seed만으로 비트 단위 재현을 주장하지 않는다. 실제 보험 업무 성과·비용·시간 효과는 미측정이다. UI와 독립 리뷰를 포함한 최종 테스트 결과는 [2차 검증결과](15_2차검증결과.md)에 모은다.
