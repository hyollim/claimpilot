# 2차 최종 결과 보고서

## 이번에 해결한 범위
기존 test 시연 중심 MVP에 신규 CSV 추론과 배치별 검토를 추가하고, 모델 순위의 활용 범위와 검색 실패를 따로 검증했다. 사기·지급 자동 판정 서비스가 아니라 담당자의 검토 순서를 돕는 단일 사용자 로컬 PoC다. 기준29d8b09, reports/baseline_mvp와 원보고서는 보존한다.

## 전달한 기능
- 업무 현황 / 청구 데이터 분석 / 청구 상세 검토 / 모델 성능 및 업무 효과 / 공식 업무 참고자료의 다섯 메뉴로 구성했다.
- UTF-8 CSV 5 MiB·5,000행·20열 계약을 검사한다. 필수 열/ID 문제는 거부하고 값 누락·미관측 범주는 경고한다. 합성6건은 시연용이며 실제 신규 청구 성과가 아니다.
- 기존 로컬 모델로 점수와 SHAP를 계산한다. joblib은 신뢰 가능한 자체 생성 로컬 파일만 쓰며 외부 업로드는 받지 않는다. SHAP 배경은 기존 train9,252행으로 제한한다.
- SQLite 배치와 new:배치ID:청구ID 기록키로 기존 평가 기록에서 분리했다. 동일 내용·모델 재업로드는 기존 배치·검토 기록을 유지한다.
- 5/10/15/20/30/40% 검토량의 실측 포집·정밀도·리프트를 제시한다. 성과 표시는 기존 라벨 test에 한정한다.

## 성과 대신 관측한 결과
원본 LR C=0.1의 test3,084건 AP는0.130255다. 상위20%617건에서72/185건(38.92%)을 포집하지만545건은 비사기 라벨이고113개 양성은 남는다. 추가 그룹 격리에서는 AP0.144584·포집44.51%, 순수1996년 평가에서는 AP0.0731656·포집23.94%였다. **분할군이 달라 성능 향상으로 주장하지 않는다.** 동일 입력 그룹은 고객/사건 그룹이 아니다. 1996년은 이번 선정에서 격리했지만 MVP에서 이미 관측하여 외부 미래 unseen 자료가 아니다.

초기 미래 입력 기반 과거22행 purge의 진단 AP0.076508은 현재 성과에서 제외했다. 미래 입력으로 과거 선정 모집단을 바꾸지 않도록 순수 연도 cutoff로 수정한 판단 이력만 남긴다.

확률 보정은 train9252/calibration1542/selection1542/test3084로 나눴다. raw_balanced Brier0.215615, raw_none0.054121, sigmoid_balanced0.054530, sigmoid_none0.054216이었다. 낮은 Brier만으로 test 관측 후 production을 바꾸지 않았다. 연구 F1이 원본과 다른 것은 임계값 선정 표본이 validation 전체에서 selection 절반으로 달라졌기 때문이다. 현재 추론 점수는 여전히 비보정 값이고 실제 사기 확률이 아니다.

검색은 기존8개 발췌+자체 작성 경로3개=11레코드다. 신규 원문URL은KB2개이며 신규 후보 본문은 권리 허락 미확보로 공개 색인에 넣지 않았다. 후보 JSON은 git 제외이고 제한 PDF는 수집하지 않았다. 기존8개에 고정한 자율 수작업 평가에서 BM25 기준0은 Recall@3 1.0이나 범위 밖2/2도 반환했다. 개발선정 기준24는 범위 밖0/2 대신 Recall@3 0.3333으로 낮아졌다. 기본 키워드는 유지하고 BM25는 옵션으로 남겼다. 외부 gold 검증이나 LLM·RAG는 아니다.

## 설명할 수 있는 설계 판단
순위 AP와 확률 정확도를 분리하고, 시간 분할에서 미래 입력으로 과거 모집단을 고르는 문제를 수정했다. 중복 입력 격리를 고객 격리로 과장하지 않고 새 입력 경고를 신뢰도나 사기 증거로 바꾸지 않았다. SHAP는 모델 내부 기여이지 인과가 아니며, 검색의 회수율과 범위 밖 false positive를 함께 공개했다.

## 아직 남은 것과 전달 상태
실제 수집지역·라벨 기준·변수 수집시점은 미검증이다. 한국 실제 보험 업무, 비용·시간 절감은 측정하지 않았다. 인증·권한·암호화·동시성·개인정보 운영체계를 구현하지 않았으며 실제 개인정보를 입력하지 않는다. 최종 사기·지급 판단은 담당자가 수행한다.

실제 CSV 업로드·새 배치 검토 저장과 독립 코드 검토의 보완을 완료했다. 실제 산출물 포함 로컬 검증과 파일이 없는 체크아웃의 범위를 나누어 확인했다. 최종 push·원격 CI 상태는 [2차 검증결과](15_2차검증결과.md)에 기록한다. main 병합·배포는 하지 않았다. 원본 데이터·모델·검토DB·개별 점수/설명은 공개 추적 대상이 아니다.
