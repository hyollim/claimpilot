# 05. 프로젝트 팩트시트

| 항목 | 확인된 값/범위 |
|---|---|
| 용도 | 공개 라벨 기반 청구 검토 순위 제안, 단일 담당자 로컬 PoC |
| 데이터 | fraud_oracle.csv, 15,420행·33열, 양성923건(5.9857%) |
| 출처 제한 | Kaggle 다운로드 출처 확인, 수집지역·라벨 판정 정의 미검증 |
| 분할 | seed42 계층 무작위, 학습9,252/검증3,084/test3,084 |
| 입력 | 19개 범주형, 라벨 포함14개 열 학습 제외 |
| 선정 | 검증 AP 최대 Logistic Regression C=0.1, test 재선정 없음 |
| test AP/P/R/F1 | 0.130255 / 0.104463 / 0.594595 / 0.177706 |
| 상위20% | 617건 중 양성72/185, 포집률38.92%, 정밀도11.67%, 리프트1.945315 |
| 오류·누락 | 상위617건 중 비사기 라벨545건, 양성113건 미포집 |
| 1996 스트레스 | 4,083건, AP0.073166, 상위20% 포집률23.94%·정밀도6.24% |
| 95% 구간 | 고정 예측500회 bootstrap: AP0.101728~0.171554, 포집률32.09~44.58%, 상위20% 정밀도9.24~14.10% |
| 입력 독립성 | 중복 입력행51개·상충그룹2개·개발-test 공통그룹19개, 고객/사건 독립성 미검증 |
| 설명 | raw log-odds SHAP, 사기 증거·인과 설명 아님 |
| 검토 저장 | SQLite 상태·메모·체크리스트·UTC 수정시각 |
| 공식 검색 | 2기관의 발췌8개 로컬 어휘 검색, 전체 약관/RAG 아님 |
| 운영 제한 | 인증·권한·동시성·개인정보 운영 미구현 |
| GitHub | hyollim/claimpilot의 feature/claimpilot-mvp 반영 완료, main 병합·배포 미실시 |
| 실행 검증 | [검증결과](검증결과.md) 기준, 여기서 pytest 총수·완료 확정 안 함 |

모델 점수는 비보정 값이다. 한국 업무 성능·비용절감·처리시간 감소는 측정하지 않았다. 1996년 라벨 일부가 원 모델 선정에 포함되어 연도 스트레스는 독립 미래검증이 아니다. 원본 데이터·모델·검토DB·개별 청구 산출물·분할명세는 .gitignore 제외 설정했으며 최종 추적 여부 확인이 필요하다.
