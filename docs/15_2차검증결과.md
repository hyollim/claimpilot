# 2차 실행·검증 결과

확인일: 2026-10-25. 로컬 환경 macOS arm64/Python3.9.6, 원격 환경 Ubuntu24.04/Python3.11. 고정 의존성은 requirements.txt를 따른다. 테스트 개수는 실행 범위의 기록이며 업무 효과 지표가 아니다.

## 실행 확인
- 원본 fraud_oracle.csv 15,420행을 사용했다. 기존 metrics.json과 data_audit.json은 baseline_mvp 사본과 바이트 동일하다. 기존 selected.joblib과 평가 분할은 추가 실험 중 변경하지 않았다.
- 저장 모델에서 학습9,252행의 범주와 SHAP 배경 평균만 추론 번들에 추가했다. 라벨 없는 합성6건을 CSV 파일로 실제 브라우저 업로드했고 분석 성공을 확인했다.
- 의도적으로 넣은 미관측1개/누락2개가 확인 사항3개로 표시됐다. 실제 사기 라벨은 만들지 않았고 합성 입력을 성능 평가에 사용하지 않았다.
- 신규 배치의 DEMO-001 상세에서 SHAP와 자료를 확인하고 검토 상태를 추가자료 요청으로 바꾸어 시연 메모를 저장했다. 저장 성공과 UTC 저장시각을 확인했다. DB는 git 제외다.
- 예산별/그룹별/연도별/가중치/보정/검색 수치는 별도 실제 실행 보고서를 따른다. 이후 test 관측을 이용해 신규 추론 모델을 재선정하지 않았다.

## 로컬 테스트
- 실제 데이터·모델·추론 번들이 있는 실행: **204 passed**, 의존성 경고14개.
- git 추적 파일만 임시 폴더에 복사한 깨끗한 체크아웃: **189 passed, 15 skipped**, 의존성 경고14개.
- 생략 대상은 원본 CSV·모델·분할·개별 점수/설명이 필요한 통합 검사다. 원본이 없는 기본 CI의 성공을 실제 모델 검증 성공으로 대체하지 않는다.
- 실제 모델 추론, SHAP 합계와 sigmoid 점수 일치, 배치 기록 격리·재연결 복원, 같은 화면의 배치 전환 필터 분리, 정답 비노출, 동적 예산, 검색·원문 메타데이터를 검사했다.
- 정수 경계는 Decimal, nullable/categorical DataFrame, 중복 ID/열·정답 열·잘못된 숫자·비유한 SHAP를 검사한다. 저장 상한 초과 시 기존 자료를 보존하는 검사도 포함한다.
- 자료 독립성·시간 cutoff·보정 자료의 역할 분리·미래 값 변경 시 과거 선정 불변성은 작은 fixture로 검사하고 실제 산출물의 분할 해시와 대조했다.
- 경고14개는 고정 Matplotlib/Pyparsing의 deprecated API 경고다. 별도 보정 연구 중의 선형대수 RuntimeWarning도 숨기지 않고 phase2_calibration.json에 기록했다. 계수와 결과는 유한하며 ConvergenceWarning은0이었다. 모든 환경의 수치 안정성을 보장하지 않는다.

## 독립 코드 검토와 수정
확정 치명적 누수/키 충돌은 발견하지 못했다. 정수 float 반올림, 자료형 대입, 필터 공유, SHAP NaN 통과 가능성, 누적 저장 한도를 보완했다. 검토자의 정적 판단과 실제 테스트 실행 범위를 구분한다. 임의로 비밀번호·개인정보·원본 청구·모델 바이너리를 공개하지 않는다.

## 원격 검증
- 첫2차 기본 CI [실패 기록](https://github.com/hyollim/claimpilot/actions/runs/40200999378): 파일이 없는 공개 체크아웃에서 실제 데이터 검사가 실행되어4개 실패했다. 원본 데이터 공개나 검사 삭제 대신 필요한 산출물의 전제 조건을 분리했다.
- 수정 커밋cce8fee의 기본 CI가 성공했다. [실제 데이터 전체 통합 실행](https://github.com/hyollim/claimpilot/actions/runs/40202460095)도 성공했다. 원격에서 다운로드→기존 학습→신규 추론 번들 준비→예산 분석→그룹·독립연도 평가→보정 연구→검색 평가→전체 pytest를 순서대로 실행했다.
- 원격 성공을 국내 실제 보험 업무 성능이나 운영 준비 완료로 해석하지 않는다. 비교표 수치는 문서에 표시한 macOS 실험 기준이며 플랫폼별 후보 차이는 별도 한계다.

## 재현
처음 실행은 README의 다운로드→학습→추론 준비를 따른다. 모델 파일은 자체 생성한 신뢰 가능한 로컬 파일만 로드한다.
```bash
python scripts/analyze_budget.py
python scripts/validate_phase2.py
python scripts/calibrate_phase2.py
python scripts/evaluate_retrieval.py
python -m pytest -q
```

## 미완료·미검증
- 신규 공식 본문6개 후보는 명시적 재이용 허락 미확보로 공개 본문 확대를 보류했다. 공개 색인에는 자체 작성 원문 경로 설명3개만 추가했다.
- 국내 실제 청구 데이터, 새로운 독립 미래/외부기관 자료, 비용·시간 절감, 실무자 사용성 실험은 검증하지 않았다.
- 운영 인증·권한·암호화·다중 사용자·감사·보관/삭제는 미구현이다. 누적 한도 초과 기록을 자동 삭제하지 않는다.
- 검색 평가 질의는 수작업 자율 구성한 작은 내부 표본이다. BM25는 범위 밖 질문을 신뢰성 있게 판별하지 못한다. LLM·RAG는 구현하지 않았다.
- main 병합과 운영 배포는 수행하지 않았다. 최종 사기 여부와 보험금 지급은 담당자가 판단한다.
