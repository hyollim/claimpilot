# 검색 평가 보고서

## 범위부터 고정
업무 참고자료 검색이며 개별 청구의 사기·지급 판단 근거를 만들지 않는다. LLM·RAG·임베딩은 사용하지 않는다. 근거는 [검색 결과 JSON](../reports/retrieval_evaluation.json), [고정 질의](../resources/retrieval_queries.json), [기존 발췌](../resources/official_sources.json), [실제 UI 색인](../resources/official_index.json)이다.

기존 KB4개·손해보험협회4개 발췌를 보존했다. 실제 UI는 자체 작성 원문 경로 안내3개를 더한 **11레코드**를 검색한다. 이는 새 원문3편을 전문 수집했다는 뜻이 아니다. 신규 원문 URL은 KB 청구절차·필요서류 **2개**이고 협회 경로 URL은 기존에 있었다. 신규3개는 record_type=navigation으로 본문 발췌와 구분한다.

[공식자료 검토](10_공식자료범위검토.md)의 후보6개 본문은 권리 허락 미확보로 공개 색인에 넣지 않았다. 후보 원본문 JSON은 로컬 검토용이며 git 제외다. 제한된 PDF를 수집·다운로드·색인하지 않았다. 기존8개를 보존했다는 사실이 전체 발췌의 최신성·이용허락을 다시 인증한 것은 아니다. 담당자는 원문과 적용일을 확인해야 한다.

## 평가 설계
검색 구현·실행 전에 사람이 작성한 **자율 수작업 질의**다. 외부 독립 gold나 실제 담당자 질의 표본이 아니다. 기존 **8문서**에 고정하고 개발 답 있는 질의8개, 고정 평가 답 있는 질의12개, 답 없는 질의4개(개발2/평가2)를 구분했다. 문서는 두 split이 공유하고 질의만 다르다. 신규 경로3개를 포함한11레코드 UI 성능으로 일반화하지 않는다.

기존 가중 키워드와 BM25를 비교했다. BM25는 정규화한 단어 내부 문자2~4그램, k1=1.2, b=0.75, 제목/기관/절/본문 가중치3/2/2/1이다. 형태소 분석·동의어 확장·의미 검색이 아니다. 질의 ngram은 중복 제거하고 동점은 ID 순으로 정렬한다. threshold는 관련도 점수 하한이지 신뢰확률이 아니다. 기준0에서도 score0은 반환하지 않는다.

개발 질의에서 기준24를 선정하고 고정 평가 후 재조정하지 않았다. Recall@3은 관련 문서의 상위3개 회수, MRR@3은 첫 관련 결과의 역순위, NDCG@3은 상위3개 관련도 순위 품질이다. 답 없는 질의는 별도로 결과가 하나라도 반환되는 비율을 센다.

## 실측 결과
|split|방법|Recall@3|MRR@3|NDCG@3|답 없는 질의 반환|
|---|---|---:|---:|---:|---:|
|개발8|키워드|0.7500|0.6875|0.7039|2/2|
|개발8|BM25 기준0|1.0000|0.8750|0.9077|2/2|
|개발8|BM25 개발선정24|0.2500|0.2500|0.2500|0/2|
|고정 평가12|키워드|0.9167|0.8750|0.8859|2/2|
|고정 평가12|BM25 기준0|1.0000|1.0000|1.0000|2/2|
|고정 평가12|BM25 개발선정24|0.3333|0.3333|0.3333|0/2|

BM25 기준0은 답 있는 평가에서 높게 나왔지만 범위 밖 평가2건도 모두 반환했다. 기준24는 그2건 반환을 막는 대신 답 있는 평가의 회수율을0.3333으로 낮췄다. 이 실패 tradeoff를 감추거나 전체 검색 품질 개선으로 요약하지 않는다. 답 없는2건에서 0/2라는 결과만으로 일반적인 무응답 안전성을 입증할 수도 없다.

## UI 결정과 한계
**키워드를 기본 유지**하고 BM25 후보와 보수적 연구를 선택 옵션으로 제공한다. BM25 함수 기본값과 UI의 기본 방식은 구분한다. 결과는 제목·기관·원문URL·확인일·발췌 위치·한계를 표시하며 경로 항목은 본문 미수집으로 안내한다. 없으면 관련 발췌 없음으로 표시하고 추정 답변을 만들지 않는다. 반환 결과가 있다고 질문의 답이 있다는 뜻은 아니다.

작은8문서의 표현 바꾸기 내부 점검이고 법률 정확성·현행 규정 적합성·담당자 업무 충분성 평가가 아니다. 실사용 동의어, 띄어쓰기, 담보 혼동과 범위 밖 질의를 넓혀 담당자가 원문을 검수하는 후속 평가가 필요하다. 공식자료 검색 score는 모델 점수·SHAP·과실비율·사기 확률과 독립적이다. 실제 비용·검색시간 절감은 측정하지 않았다. 구현 검증은 [2차 검증결과](15_2차검증결과.md)를 따른다.
