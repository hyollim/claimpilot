# ClaimPilot

공개 자동차보험 청구 데이터의 검토 순서를 제안하는 단일 담당자 로컬 PoC다. 모델 점수와 SHAP 검토 단서, 상태·메모·체크리스트 저장, 공식 발췌 검색을 제공한다. 사기 여부·보험금 지급을 자동 확정하지 않는다.

## 현재 결과와 한계
- 데이터 15,420행·33열, 양성 라벨 923건(5.99%). 수집 지역과 원래 라벨 판정 기준은 미검증이다.
- 선정: Logistic Regression C=0.1. 최종 test 3,084건에서 AP 0.130255, Precision 0.104463, Recall 0.594595, F1 0.177706.
- 상위 20% 617건에서 양성 라벨 72/185건을 포집했다(포집률 38.92%, 정밀도 11.67%, 리프트 1.945315). 545건은 비사기 라벨(0)이며, 양성 113건은 상위 20% 밖에 남았다.
- 1996년 연도 스트레스 AP 0.073166, 상위 20% 포집률 23.94%. 원 모델 선정에 1996년 일부 라벨이 포함되어 독립 미래검증이 아니다.
- 점수는 비보정 값이며 실제 사기 확률이 아니다. 한국 업무 성능·비용절감·처리시간 감소는 측정하지 않았다.

수치 근거: [metrics.json](reports/metrics.json), [data_audit.json](reports/data_audit.json). [모델 평가](docs/03_모델평가보고서.md)에 95% 구간과 비교 결과를 기록했다.

## 실행
프로젝트 루트에서 실행한다. 데이터 이용조건과 다운로드 가능 여부는 [Kaggle 원문](https://www.kaggle.com/datasets/shivamb/vehicle-claim-fraud-detection)을 확인한다.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/download_data.py
python scripts/train.py
python -m pytest -q
python -m streamlit run app.py
```

실제 학습 산출물을 포함한 테스트 53개가 통과했다. 산출물이 없는 체크아웃에서는 47개 통과·6개 생략이며, 학습 후 전체 검증을 실행한다. 환경과 범위는 [검증결과](docs/검증결과.md)에 기록했다. 개발 중 특수 환경 문제는 [개발판단기록](docs/개발판단기록.md)에만 기록한다.

## 사용 범위
- 청구 검토 → 건 선택 → 모델 기여도와 원본 자료 대조 → 상태·메모·체크리스트 저장. 검토완료는 지급 승인이나 사기 확정이 아니다.
- 성능 평가 탭의 정답 라벨과 검토 화면을 분리한다. 실제 개인정보를 입력하지 않는다.
- 공식 검색은 KB손해보험·손해보험협회 자료의 로컬 발췌 8개에 대한 어휘 검색이다. 전체 약관 검색이나 생성형 RAG가 아니며, 모델 설명과 독립적이다.
- 운영 인증·권한·동시성 제어·개인정보 운영체계는 미구현이다. 외부 공개 서비스로 사용하지 않는다.
