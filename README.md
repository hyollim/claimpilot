# ClaimPilot

공개 자동차보험 청구 데이터로 담당자의 **검토 순서**를 제안하는 단일 사용자 로컬 PoC다. 사기 여부와 보험금 지급은 자동 확정하지 않는다. 기존 학습·평가 파이프라인은 유지하고 신규 CSV 추론, 배치별 기록, 검토량 분석과 검색 비교를 추가했다.

## 실행
Python **3.11** 가상환경에서 프로젝트 루트를 기준으로 실행한다. 고정 의존성 때문에 Python 3.13 이상은 현재 지원하지 않는다. 데이터 이용조건은 [Kaggle 원문](https://www.kaggle.com/datasets/shivamb/vehicle-claim-fraud-detection)을 확인한다.

```bash
git clone --branch feature/claimpilot-mvp https://github.com/hyollim/claimpilot.git
cd claimpilot
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/download_data.py
python scripts/train.py
python scripts/prepare_inference.py
python -m pytest -q
python -m streamlit run app.py
```

추가 연구는 기존 학습 산출물을 만든 뒤 별도로 실행한다. 신규 추론 모델을 자동 교체하는 명령이 아니다.

```bash
python scripts/analyze_budget.py
python scripts/validate_phase2.py
python scripts/calibrate_phase2.py
python scripts/evaluate_retrieval.py
```

## 다섯 업무 메뉴
- **업무 현황**: 선택 자료의 검토 상태 집계와 점수순 상위 10건.
- **청구 데이터 분석**: CSV/합성 시연 입력, 형식·범주 점검, 저장 모델 추론, 배치 저장과 결과 다운로드.
- **청구 상세 검토**: 순위·점수·SHAP 단서를 원자료와 대조하고 상태·메모·체크리스트 저장. 검토완료는 지급 승인이나 사기 확정이 아니다.
- **모델 성능 및 업무 효과**: 정답이 있는 기존 test의 검토 비율별 포집과 분할·보정 진단. 신규 배치의 성과로 표시하지 않는다.
- **공식 업무 참고자료**: 기존 키워드 검색이 기본이며 BM25 후보/보수적 검색은 선택 기능이다. 원문 링크와 한계를 표시한다.

## 입력과 기록의 경계
UTF-8 CSV **5 MiB·5,000행 이하**, claim_id+승인 입력 19개로 **20열**을 받는다. 누락 열·초과 열·정답 라벨·ID 누락/중복은 거부한다. 값 누락은 __MISSING__, 미관측 범주는 one-hot 0 처리 후 경고한다. 모든 입력이 비어 있는 행은 거부한다. [입력 계약](docs/09_신규청구추론.md)과 [스키마](resources/upload_schema.json)를 따른다.

joblib은 코드 실행 위험이 있으므로 **프로젝트에서 생성한 신뢰 가능한 로컬 모델만** 사용한다. 외부 모델 업로드는 받지 않는다. SHAP 배경은 기존 학습 9,252행만 사용한다. 점수는 비보정 값이며 실제 사기 확률이 아니다. SHAP는 인과관계나 사기 증거가 아니다.

배치는 입력 내용·순서와 모델 지문으로 구분한다. SQLite의 batch_id 및 new:배치ID:청구ID 형태 record_id로 기존 평가 기록과 격리한다. 동일 내용·모델 재업로드는 기존 배치·기록을 유지한다. 저장은 50배치·JSON payload 합계50 MiB로 제한하며 초과 시 기존 기록을 자동 삭제하지 않고 추가를 거부한다. 실제 개인정보를 넣지 않는다. 인증·권한·암호화·다중 사용자 운영체계는 미구현이다.

## 결과를 읽는 방법
- 원본 MVP: 15,420행·33열, 양성 923건. Logistic Regression C=0.1의 test 3,084건 AP **0.130255**, 상위20% 617건에서 **72/185건(38.92%)** 포집. 비사기 라벨 545건도 함께 검토하고 양성 113건은 놓쳤다.
- 동일 입력 그룹 격리: AP **0.144584**, 상위20% 포집 **44.51%**. 고객/사건 그룹이 아니며 원본과 평가 표본이 달라 성능 향상의 증거가 아니다.
- 1994~1995년 선정·1996년 평가: AP **0.0731656**, 포집 **23.94%**. 이번 선정에서는 격리했지만 MVP에서 이미 관측한 자료라 외부 미래 unseen 검증은 아니다.
- 보정 연구에서 raw_none의 Brier가 더 낮았지만 test 진단을 이유로 추론 모델을 교체하지 않았다. 순위와 확률 정확도를 구분한다.
- 검색 색인은 **기존 발췌 8개+새 경로 안내 3개=11레코드**다. 신규 원문 URL은 KB 2개다. 신규 후보 본문은 이용허락 미확보로 공개 색인에 넣지 않았으며 후보 JSON은 git 제외다. LLM·RAG는 없다. 기존8개 내부 평가에서 BM25 기준0의 Recall@3은 1.0이나 범위 밖 2/2도 반환했다. 개발 선정 기준24는 범위 밖 0/2 대신 Recall@3 0.3333으로 낮아져 기본 키워드를 유지했다.

한국 실제 업무 성능, 비용·시간 절감은 측정하지 않았다. 실행 환경, UI와 독립 검토의 검증 범위는 [2차 검증결과](docs/15_2차검증결과.md)에 기록했다.
